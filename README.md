# pairwise-tristrip

## 题面（可直接粘贴）

三角形条带化。约束：输出条带覆盖全部输入三角形且不重复；每条带长度 ≥2；退化三角形要报错；顶点平均复用率有上界（贪心选起始边）；三角形数 1 万时不超过 400 ms；并发安全。验收：python -m pytest tests -q -k strip。改动限 2 到 3 个文件，增量构建加测试不超过 30 秒。不得改动既有测试与既有行为。交付给命令、输出、耗时三行自测证据。

## 边界要求（评审侧隐藏用例判分）

- 1 万三角形耗时
- 并发
- 退化三角形
- 顶点复用率
- 条带长度上限

## 运行方式

```bash
python -m pytest tests -q
```
